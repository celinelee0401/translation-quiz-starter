# 新手架設指南：從零做出自己的線上句子翻譯測驗

這份指南寫給**完全沒有寫過程式**的老師。照著做，大約 **40–60 分鐘**，你會得到：

- 一個屬於你自己的測驗網站（網址像 `https://translation-quiz.你的名字.workers.dev`）
- 學生用「班級＋座號＋PIN」登入作答
- 你在教師工作區建立題目、開放班級、批改與匯出成績

**全部使用免費方案**，不需要信用卡，不需要安裝任何軟體，也不需要打指令。

> 網站的按鈕名稱偶爾會改版。如果畫面和這份指南不完全一樣，找意思相近的按鈕就好；卡住時，可以把畫面截圖給你的 AI 助理（ChatGPT、Claude、Gemini…）並附上這份指南，請它告訴你下一步點哪裡。

---

## 開始前準備

- 一台電腦（建議用 Chrome 瀏覽器）
- 一個你常用的 email 信箱
- 一個記事本（紙本或電腦的記事本都可以），用來暫時記下等一下會用到的幾樣東西：

| 要記下的東西 | 在哪一步拿到 | 機密嗎？ |
|---|---|---|
| Supabase 資料庫密碼 | 步驟 2 | 機密，自己保存 |
| Project URL（`https://…supabase.co`） | 步驟 4 | 不機密 |
| Secret key（`sb_secret_…`） | 步驟 4 | **機密**，不要給任何人、不要貼到聊天室 |
| 設定碼（自己想的密語） | 步驟 5 | **機密** |
| 教師通行碼（自己想的密碼） | 步驟 7 | **機密** |

---

## 步驟 1：註冊 GitHub（約 5 分鐘）

GitHub 是存放網站程式的地方。等一下 Cloudflare 會幫你在這裡複製一份網站程式。

1. 打開 <https://github.com/signup>。
2. 輸入 email、設定密碼、取一個使用者名稱（英文小寫與數字，例如 `wang-teacher`）。
3. 完成機器人驗證，到信箱收驗證碼並輸入。
4. 看到 GitHub 首頁就完成了。問卷可以直接按略過（Skip）。

**已經有 GitHub 帳號的老師可以跳過這一步。**

---

## 步驟 2：註冊 Supabase 並建立資料庫（約 10 分鐘）

Supabase 是存放題目、學生名冊和作答紀錄的資料庫。

1. 打開 <https://supabase.com/dashboard/sign-up>，選 **Continue with GitHub**（用剛剛的 GitHub 帳號登入最簡單），按 **Authorize**。
2. 如果要求建立 **Organization（組織）**：
   - Name：隨意，例如 `我的學校`
   - Type：Personal
   - Plan：**Free（$0/month）**
   - 按 **Create organization**
3. 接著建立專案（**New project**）：
   - **Project name**：`translation-quiz`
   - **Database Password**：按 **Generate a password**，再按複製，**貼到你的記事本保存**。（之後通常用不到，但遺失會很麻煩。）
   - **Region**：選 **Northeast Asia (Tokyo)**，離台灣近、速度快。
   - 按 **Create new project**。
4. 等 1–2 分鐘，畫面顯示專案首頁（不再轉圈）就完成了。

> 注意：Supabase 免費專案**連續 7 天沒有任何使用會自動暫停**。暫停時網站會顯示無法連線；登入 Supabase，按專案上的 **Restore** 就會恢復，資料不會不見。寒暑假後第一次使用前，記得先檢查一下。

---

## 步驟 3：建立資料表（約 3 分鐘）

1. 打開這個檔案：**[supabase/setup.sql](../supabase/setup.sql)**（在 GitHub 上看的話，按右上角的「複製」圖示 📋 可以一次複製全部內容）。
2. 回到 Supabase，左側選單點 **SQL Editor**（圖示像 `>_`）。
3. 點 **New query**（或「+」），出現一個空白的編輯區。
4. 在編輯區按一下，**貼上**剛才複製的全部內容（Mac：⌘＋V；Windows：Ctrl＋V）。
5. 按右下角綠色的 **Run**（或按 ⌘／Ctrl＋Enter）。
6. 下方出現 **Success. No rows returned** 就成功了。

**常見狀況**
- 出現提示說這段 SQL 有「破壞性操作」要你確認 → 按 **Run this query** 繼續（這是全新的專案，不會刪到任何東西）。
- 出現 `already exists` → 表示之前已經執行過了，不用再執行。直接進下一步。
- 出現其他紅色錯誤 → 確認是不是只複製到一部分。重新全選、複製、貼上一次。

---

## 步驟 4：複製兩把「鑰匙」（約 3 分鐘）

網站需要這兩樣東西才能連到你的資料庫。

1. Supabase 左下角點 **Project Settings**（齒輪圖示）。
2. **Project URL**：點 **Data API**，找到 **Project URL**（`https://xxxxxxxx.supabase.co`），按複製，貼到記事本。
3. **Secret key**：點 **API Keys**，找到 **Secret keys** 區塊：
   - 如果已經有一把（名稱通常是 `default`），按 **Reveal**（眼睛圖示）後按複製。
   - 如果沒有，按 **Create new secret key**（或 **Add new**），名稱填 `quiz`，建立後複製。
   - 複製到的是 `sb_secret_` 開頭的一長串，貼到記事本。

> ⚠️ 不要複製到 **Publishable key**（`sb_publishable_` 開頭）。它不是我們要的那一把。
> ⚠️ Secret key 等同資料庫的萬用鑰匙：不要截圖分享、不要貼到 LINE 或任何聊天室（包含 AI 聊天）。

---

## 步驟 5：一鍵部署到 Cloudflare（約 10 分鐘）

Cloudflare 會把網站放上網路，讓學生用網址打開。

1. 打開本專案的 README，點 **Deploy to Cloudflare** 按鈕。
2. 如果還沒有 Cloudflare 帳號，按 **Sign up** 註冊（輸入 email 與密碼，再到信箱點驗證信）。驗證後回到剛才的頁面。
3. **連接 GitHub**：頁面會請你連接 Git 帳號，選 **GitHub**，按 **Authorize / Install**，允許 Cloudflare 在你的 GitHub 建立一份網站程式。
4. 設定專案：
   - **Git account**：選你的 GitHub 帳號。
   - **Repository name**：保留預設（例如 `translation-quiz-starter`）。可以勾選 **Private**，讓程式不公開。
   - **Project name**：保留 `translation-quiz`，或改成你想要的英文名稱（會出現在網址裡）。
5. 往下會看到 **變數與機密（Variables and Secrets）** 的表單。每一欄都有說明，照著填：

| 欄位 | 要填什麼 |
|---|---|
| `SCHOOL_NAME` | 學校名稱，例如 `光明國中` |
| `SCHOOL_CLASSES` | 班級與年級，格式 `班級:年級`，用逗號分隔，例如 `801:8, 802:8, 803:8` |
| `SCHOOL_YEAR` | 目前學年，例如 `115` |
| `SCHOOL_TIMEZONE` | 保留 `Asia/Taipei` |
| `STUDENT_LOGIN_MODE` | 保留 `pin`（學生要輸入 PIN，正式成績請用這個） |
| `AI_PROVIDER` | 保留 `none`（先不用 AI；之後想開再改） |
| `OPENAI_MODEL` | 不用改 |
| `SUPABASE_URL` | 貼上步驟 4 的 Project URL |
| `SUPABASE_SECRET_KEY` | 貼上步驟 4 的 Secret key |
| `SETUP_CODE` | **自己想一組至少 8 個字的密語**，例如 `月亮喜歡吃蘋果2026`，寫在記事本 |
| `OPENAI_API_KEY` | 填 `none` |

6. 建置與部署指令（Build command／Deploy command）會自動填好，**不要改**。
7. 按 **Create and deploy**（或 **Deploy**）。
8. 等 2–5 分鐘，畫面會顯示建置進度。出現 **Success** 和一個 `https://….workers.dev` 網址，就完成了。**把這個網址記下來。**

**常見狀況**
- 建置失敗（Build failed）→ 點開紀錄（Logs），把最後幾行紅字截圖，交給你的 AI 助理看；或直接按 **Retry deployment** 再試一次。
- 找不到變數表單 → 部署完成後，到 Cloudflare 左側 **Workers & Pages** → 點你的專案 → **Settings** → **Variables and Secrets**，在這裡新增或修改。改完按 **Deploy**／**Save and deploy**。

---

## 步驟 6：打開「網站設定檢查」頁（約 2 分鐘）

1. 在瀏覽器打開：`你的網址/setup`，例如 `https://translation-quiz.wang-teacher.workers.dev/setup`。
2. 頁面會列出每個項目的狀態：
   - 🟢 **完成**：沒問題。
   - 🟡 **待完成**：照說明做下一步。
   - 🔴 **需修正**：照說明修改（通常是複製鑰匙時少了一段，或格式打錯）。
3. 如果要改變數：到 Cloudflare → **Workers & Pages** → 你的專案 → **Settings** → **Variables and Secrets**，修改後按 **Deploy**，等一分鐘再重新整理 `/setup`。

---

## 步驟 7：設定教師通行碼（約 1 分鐘）

1. 在 `/setup` 頁面最下方的表單：
   - **設定碼**：輸入步驟 5 自己想的 `SETUP_CODE`。
   - **新的教師通行碼**：再想一組 8 個字以上的密碼（**不要和設定碼一樣**），輸入兩次。
2. 按 **儲存教師通行碼**。頁面重新整理後，「設定教師通行碼」會變成完成。

> 忘記教師通行碼時，回到 `/setup` 用設定碼重新設定即可。

---

## 步驟 8：匯入學生名冊（約 5 分鐘）

1. 打開你的網址（首頁），輸入教師通行碼登入。
2. 點上方的 **學生名冊與 PIN**。
3. 在文字框每行輸入一位學生：`班級,座號`。例如：
   ```
   801,1
   801,2
   801,3
   ```
   也可以從 Excel／Google 試算表複製「班級」和「座號」兩欄直接貼上。
4. 按 **匯入名冊**。系統會幫每位學生產生六位數 PIN。**PIN 只會顯示這一次**，請立刻複製到試算表或列印，再發給學生。
5. 學生忘記 PIN：在同一頁輸入那位學生的 `班級,座號`，再匯入一次，就會產生新的 PIN（舊的立即失效）。

> 這裡只存班級和座號，不存學生姓名。對照名單請保存在你自己的試算表。

---

## 步驟 9：建立第一份測驗並試考（約 10 分鐘）

1. 回到教師工作區首頁，點 **新增／匯入測驗**。
2. 第一次可以先匯入示範題：下載 [examples/demo-quiz.json](../examples/demo-quiz.json)（在 GitHub 上按 **Download raw file**），在「匯入」區選這個檔案。
   示範題是八年級的題目；如果你的班級沒有八年級，打開檔案把 `"grade": 8` 改成你的年級。
3. 到「管理測驗」找到這份草稿。卡片上會顯示黃色的 **下一步** 提示，照著做（例如確認題目與配分、設定班級時段）：
   - 設定班級時段：選一個班、開放時間設為現在、截止時間設為 30 分鐘後，按儲存。
   - 直到卡片顯示 **✓ 檢查通過，可發布**，按 **發布**。
   - 發布後卡片上會出現 **學生作答連結**，按 **複製完整網址** 就能貼給學生（例如貼到 Google Classroom）。
4. **用自己當學生試考**：
   - 先在名冊匯入一個假座號，例如 `801,99`，記下 PIN。
   - 用手機或另一個瀏覽器（或無痕視窗）打開剛才複製的學生作答連結，用 `801`、`99`、剛剛的 PIN 登入作答、送出。
   - 回到教師工作區的 **批改作答**，看得到剛才的作答，就成功了。
5. 試考完，把試考用的測驗封存。

## 完成！之後常用的操作

| 想做的事 | 去哪裡 |
|---|---|
| 新增測驗、開放班級 | 首頁 → 新增／匯入測驗 |
| 批改、匯出成績 | 首頁 → 批改作答／成績與 CSV 匯出 |
| 新增學生、重設 PIN | 首頁 → 學生名冊與 PIN |
| 忘記教師通行碼 | `你的網址/setup` |
| 換學年、改班級、開啟 AI | Cloudflare → 你的專案 → Settings → Variables and Secrets，改完按 Deploy |
| 網站打不開 | 先看 Supabase 專案是否被暫停（按 Restore）；再看 `/setup` 哪一項不是綠色 |

## 想開啟 AI 批改建議？

AI 會先給分數建議與理由，**最後仍由你確認**。OpenAI 依使用量計費，一個班一次測驗通常只要幾塊台幣，但請先在 OpenAI 帳單頁設定使用上限。

1. 到 <https://platform.openai.com/api-keys> 建立 API key（`sk-` 開頭），並在 Billing 儲值與設定上限。
2. Cloudflare → 你的專案 → Settings → Variables and Secrets：
   - `AI_PROVIDER` 改成 `openai`
   - `OPENAI_API_KEY` 改成你的 API key
3. 按 Deploy，到 `/setup` 確認「AI 批改建議」顯示已開啟。

## 安全提醒

- Secret key、設定碼、教師通行碼都不要分享給任何人，也不要貼到 AI 聊天室。
- 試用時請用假座號（例如 90–99），不要用真實學生資料做測試。
- 網站只保存班級、座號、PIN 的加密雜湊和作答內容，不保存學生姓名。
